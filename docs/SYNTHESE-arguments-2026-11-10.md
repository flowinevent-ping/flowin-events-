# Synthèse des arguments, bénéfices et avantages (10/11/2026) — avant scénarisation

Source : dictée de Romain du 10/11 (`docs/ARGUMENTAIRE-flowin-event.md`). Bénéfice = ce que la cible
y gagne ; avantage = ce qui le rend possible / différent.

## Flowin Animation

### Pour le commerce
| Bénéfice | Avantage Flowin |
|---|---|
| Un **fichier client**, même quand on n'en a pas (restaurant) | Chaque joueur laisse ses coordonnées |
| Des clients qui **reviennent** (récurrence) | Lots = offres promotionnelles : remise, produit, service, produit complémentaire sur un premier achat ; gain immédiat ou sur le prochain achat |
| Des **nouveaux clients** | Captation du flux passant + **parrainage** (le lot peut être offert à un proche) |
| **Moins cher** que conquérir : un nouveau client coûte 3 à 5 fois plus | On anime sa propre clientèle |
| Une **marque renforcée** | Quiz sur le métier, le commerce, la marque |
| **Connaître son public**, préparer ses offres | Questions bonus = sondage |
| **Aucun effort** dans la durée | Animation automatique sur la période choisie (année ou temps forts), jeux variés |
| **Mieux qu'une carte de fidélité** | Interaction, connaissance, fichier vivant |
| **Visibilité** et statut de **commerce référent** | Réseau Flowin : avantages que les non-participants n'ont pas |
| Savoir **ce qui marche** | Un QR par support, chaque campagne mesurée |

### Pour le participant
| Bénéfice | Avantage |
|---|---|
| **Gagner** : remise, produit, service, immédiatement ou au prochain passage | Jeux variés : quiz, bonus, roulette, tombola |
| **S'amuser** et **découvrir** le métier, le commerce | Quiz court, sans appli |
| **Faire plaisir** : offrir son lot, faire jouer ses amis | Parrainage récompensé |
| **Des avantages exclusifs** dans les commerces Flowin | Réseau de commerces référents |

## Flowin Super Event

### Pour l'organisateur
| Bénéfice | Avantage |
|---|---|
| **Diffusion démultipliée** de son événement, en hyperlocal | Réseau de commerces : affiche physique + application + clients des commerces + leurs réseaux sociaux |
| **Plus de fréquentation** | Lots avant l'événement : places, passes, goodies |
| **Mesurer la fréquentation** sur place | Le festival devient station jeu (un ou plusieurs points) |
| **Renforcer la marque** de l'événement | Quiz de l'événement |
| **Sonder** : mobilité, RSE, éco-responsabilité, sécurité | Questions bonus |
| **Garder le contact**, annoncer les prochaines dates | Fichier participants + parrainage récompensé, offres réservées |
| **Rayonnement local**, dynamique économique, preuves pour partenaires et institutions | Chiffres (NDS 2026 : 56 % souhaitent garder le contact, plus de 70 lots dans les commerces) |

### Pour le commerce
| Bénéfice | Avantage |
|---|---|
| **Visible auprès des festivaliers**, sans le coût d'une communication de festival | Station jeu ou simple sponsor, sur les supports et la carte Flowin |
| **Du trafic et des clients** en boutique | Carte = jeu de piste ; jeu avec obligation d'achat ; lot spécial par boutique |
| **Communiquer** comme partenaire de l'événement | Choix du ou des événements |
| **Faire grandir son fichier client** | Quiz, bonus, sondage dans son commerce |

### Pour le participant
| Bénéfice | Avantage |
|---|---|
| **Gagner** avant (places, passes, goodies) et pendant (lots des commerces) | Jeu dans les commerces et sur le site |
| **Une chasse aux trésors** dans la ville | Carte des stations, lot spécial par boutique, tirage |
| **Être informé** des prochaines dates, offres exclusives | Inscription Flowin, parrainage récompensé |

## Audit du scénario V3 au regard de cette synthèse
- **Manquent** (Animation) : fichier client pour ceux qui n'en ont pas ; offre promotionnelle et produit complémentaire sur un premier achat ; gain immédiat ou au prochain achat ; animation automatique sur la période ; mieux qu'une carte de fidélité ; argument 3 à 5 fois moins cher ; parrainage par le lot offert ; commerce référent du réseau ; variété des jeux (roulette, tombola).
- **Erreur** : film A centré sur une boulangerie → à remplacer par un **commerce type**.
- **Manquent** (Super Event organisateur) : festival = station jeu (traçage de la fréquentation) ; outil de sondage cité (éco-responsabilité) ; parrainage récompensé et prochaines dates ; offres réservées ; rayonnement économique local.
- **Manquent** (Super Event commerce) : coût de communication inaccessible ; carte = jeu de piste ; obligation d'achat ; lot spécial par boutique ; choix du ou des événements ; station jeu **ou** simple sponsor ; lots offerts par le festival avant, par les commerces pendant.
- **Absent partout** : un film ou des plans du point de vue du **participant** (ce qu'il gagne).
