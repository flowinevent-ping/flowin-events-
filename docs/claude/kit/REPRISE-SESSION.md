# Reprise de session
Une session s'arrête vers 60 % de contexte. Avant : réécrire l'état dans le fichier de ton entrée (`univers/` ou `kit/AUTOMATISATION.md`), lignes de `A-FAIRE.md`, 1 ligne `JOURNAL.md`, ta ligne `ETAT.md`. Nouvelle session « Flowin Event · <Entrée> » : lire ESSENTIEL (automatique), ton fichier, tes lignes de `A-FAIRE.md`. Rien d'autre.
Si quelque chose casse : `docs/claude/PLAN-DE-REPRISE.md` (agent `continuite-reprise`) ; tag git avant toute migration risquée.
Anciennes sessions : on les archive, on ne les supprime jamais.
