# Carnet d'améliorations (créé le 21/11/2026 ; ≤150 lignes)

Les 4 agents critiques (`critique-ergonomie`, `critique-innovation`, `critique-performance-donnees`, `veille-marche`) PROPOSENT ; Romain décide ; l'agent principal transforme les propositions validées en missions pour les agents exécutants. Jamais de changement de code par un critique.

## Règles
- Seules les propositions avec preuve (mesure, source datée, observation d'écran) entrent ici. Sans preuve : « non vérifié », pas de proposition.
- Au plus 5 nouvelles propositions par critique et par passage ; passage mensuel (1er jour ouvré, avec l'élagage) ou à la demande. Premier passage : 21/11/2026 ; prochain : 01/12/2026.
- Statuts : proposée / validée par Romain / refusée / faite. Une proposition refusée RESTE dans le carnet avec la raison de Romain : on ne la re-propose pas.
- Respect de REGLES.md : pas de violet ni d'emoji, carrousel, peu de texte, moins de clics, aucune donnée inventée, aucune baisse de sécurité ni changement du consentement.
- Impact et effort de 1 (faible) à 5 (fort). Effort calibré pour une entreprise d'une personne. Réglementaire : toujours « à faire valider par un juriste ».
- Seul l'agent principal écrit dans ce fichier (les critiques proposent des lignes dans leur rapport).
