# Profil Organisateur (Super Event)
Entrée : « Flowin Event · Organisateur ». Voir aussi `COMMUN.md` (Design).

## Ce qui est propre
Il crée un Super Event, fixe ses lots, accepte ou invite des stations (commerces), suit la carte et les passages. Le tirage est piloté par Flowin, pas par lui.

## Règles
Super Event = toujours tirage au sort, pas de gain immédiat ni de roue. Deux phases (avant, pendant). Pas de prix public : sur étude. Les partenaires diffusent l'événement, ils ne le financent jamais.

## Argent
Aucun prix public. Étude au cas par cas : `paiement.md`.
