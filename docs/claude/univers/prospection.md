# Rubrique Prospection et communication
Entrée : « Flowin Event · Prospection ». Agent : `marketing-prospection` ; veille : `veille-marche`.

## Ce qui est propre
Cibles, séquences, textes de prospection, e-mails, réseaux sociaux, annonces des commerces, relances. Rien ne part sans le go de Romain.

## Règles
Tout envoi (e-mail, SMS, WhatsApp, courrier, réseau) exige le go explicite de Romain. Pas de campagne d'acquisition : on travaille sur l'existant. Annonces des commerces : dans l'application seulement. Plafond du mailer : voir `ETAT.md`. Règles légales (prospection e-mail, données, mineurs) vérifiées avant le premier envoi.
