Exporter les chiffres
maquette · exemple
Colonnes réelles. Flashs = lignes de visites (event_id, created_at) pour l’animation, nombre d’ouvertures par QR. Contacts autorisés = joueurs.optin vrai. Hommes / femmes = joueurs.genre (vide = non renseigné). Âge = joueurs.tranche_age (la table a aussi age_tranche : à vérifier laquelle est remplie, les libellés sont des exemples). Code postal = joueurs.code_postal. Chalandise : joueurs.adresse (distance au commerce, géocodage à prévoir) ; vue « au scan » = participations.scan_distance_m. Pas de « passages attendus » sur cet écran. Tous les chiffres sont des exemples. Un contact sans autorisation n’est jamais montré en détail (seulement des parts).
