## 2. Constats transverses
- Prix incohérents entre trois sources : `lib/reglement.ts` (445 / 990 / 110 ; quiz 145 / 72,50), `bon-commande-animation.html` (990 / 110 ; quiz 180, bonus 180) et les CGV (pas de 445). À aligner en une seule livraison (Lot A).
- Chaîne publication -> paiement -> contrôle cassée : le parcours publie et affiche le RIB, mais aucune trace de paiement n'est créée, donc ni alerte SA, ni email.
- Mention « Tarifs à confirmer » encore visible alors que les prix sont décidés.
- Aucune vérification de bout en bout n'a été faite pour les critères de livraison (tous non cochés dans le PLAN).
